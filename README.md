# Voice-Assistant-
# مشروع المساعد الصوتي باستخدام Gemini API

## وصف المشروع

هذا المشروع عبارة عن مساعد صوتي يعتمد على الذكاء الاصطناعي، حيث يستطيع المستخدم التحدث عن طريق الميكروفون، ثم يتم تحويل الكلام إلى نص وإرساله إلى Gemini API للحصول على الرد المناسب، وبعد ذلك يتم عرض الرد على الشاشة ونطقه باستخدام خاصية تحويل النص إلى كلام.

## التقنيات المستخدمة

- HTML
- CSS
- JavaScript
- PHP
- Google Gemini API
- XAMPP (Apache)

## طريقة تشغيل المشروع

1. تشغيل برنامج XAMPP.
2. تشغيل خدمة Apache.
3. وضع مجلد المشروع داخل مجلد htdocs.
4. فتح المشروع من خلال الرابط:
     http://localhost/hw3set/
   5. السماح للمتصفح باستخدام الميكروفون.

## المشاكل التي واجهتنا

أثناء تنفيذ المشروع واجهنا عدة مشاكل قبل أن يعمل المشروع بالشكل المطلوب، ومن أهمها:

- في البداية لم يكن الميكروفون يعمل بسبب استخدام متصفح لا يدعم خاصية التعرف على الصوت بشكل كامل، وتم حل المشكلة باستخدام متصفح Google Chrome.

- بعد ذلك ظهرت أخطاء في الخادم (Server Error)، وكان السبب وجود أخطاء في مسارات الملفات وإعدادات ملفات PHP، وتم تعديلها حتى أصبح الاتصال يعمل بشكل صحيح.

- واجهنا أيضاً بعض الأخطاء البرمجية في ملف JavaScript، والتي كانت تمنع إرسال الطلبات إلى الخادم، وتم اكتشافها من خلال أدوات المطور في المتصفح وإصلاحها.

- استغرقت مشكلة الربط مع Gemini API وقتاً أطول من المتوقع، حيث ظهرت عدة رسائل خطأ مثل مشكلة الحصة (Quota) وعدم العثور على النموذج (Model). وبعد مراجعة النماذج المتاحة في الحساب اكتشفنا أن اسم النموذج المستخدم داخل المشروع غير متوافق مع المفتاح الذي تم إنشاؤه.

## كيفية حل المشكلة

بعد التأكد من النماذج المتوفرة في الحساب تم تغيير اسم النموذج من:
gemini-2.0-flash

إلى:
gemini-flash-latest

وبعد تعديل اسم النموذج والتأكد من صحة مفتاح API، تم الاتصال بـ Gemini API بنجاح وأصبح المشروع يعمل دون مشاكل.

## النتيجة النهائية

تم تنفيذ المشروع بنجاح، وأصبح بإمكانه:

- استقبال صوت المستخدم.
- تحويل الصوت إلى نص.
- إرسال النص إلى Gemini API.
- استلام الرد من الذكاء الاصطناعي.
- عرض الرد داخل الصفحة.
- نطق الرد صوتياً للمستخدم.
